# Project Vision

Phone Home contains AetherForge: an offline-first iOS emergence laboratory for exploring procedural worlds, proto-agent adaptation, detector swarms, and quantum-inspired formula learning.

The core direction is not a decorative planet toy. The target is a reproducible artificial-life sandbox where a user can create a world, seed Sparks, run deterministic steps, and compare how complexity, entropy, habitability, and grounded Spark counts evolve.

## v0.86 identity

AetherForge v0.86 focuses on scientific usefulness:

- deterministic seeded RNG
- Spark lineage tracking
- metrics history frames
- grouped RealityKit scene rotation
- local JSON persistence
- offline-first execution

## North star

Same seed. Same parameters. Same steps. Same result.
