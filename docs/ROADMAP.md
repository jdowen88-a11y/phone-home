# Roadmap

## v0.86 current

- Deterministic seeded RNG
- Spark lineage fields
- Metrics history frames
- Grouped RealityKit planet scene
- Formula library
- Local JSON persistence

## v0.90 next

- True ray/sphere picking instead of screen-space tap mapping
- Generated mesh terrain chunks instead of point-sphere tiles
- Layer-specific render cache for terrain, Sparks, hotspots, atmosphere, and overlays
- Experiment presets
- Snapshot history browser
- Export/import of worlds and simulation runs

## v1.0 target

- SwiftData persistence
- Time-series charts
- Experiment comparison mode
- Anomaly logging
- Accessibility labels
- Haptics
- Localization
- Unit tests and performance profiling
